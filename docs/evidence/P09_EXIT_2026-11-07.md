## Limits

- **Accessibility.** No real screen reader has been used, so the announcement of moves, groups and refusals is unproven (#376, open). Firefox, WebKit and the packaged Electron shell were not checked, nor ring contrast or clipping. The criterion as written is audit and keyboard, and those are what the tests show.
- **Dogfooding.** One Windows machine, from source, one run per project. Journey D is unsupported on three projects. On shadcn-ui, B and E run on an inserted text layer, because its components hold only `{…}` parts.
- **#377 stays open.** A selection refused as `project-changed` is accepted by the founder's decision and still reported. `GET` 409s were seen in two runs with temporary driver changes, and their cause is inferred. None occurred in the recorded run, and the driver's routing may have shifted the race's timing, so journey F may yet fail intermittently.
- **Styles.** Overlapping pairs outside the overlap table are not reported. Invalid fallback values still win (#383), and values that are themselves unbalanced remain open (#382).
- **Code parts.** Pasted parts from before #362 keep exporting as literal text, a documented limit on #370.
- **Keyboard.** After a nested layer is deleted from the button, focus lands on the page's row, where Enter then Delete removes the page. It takes deliberate key presses. After a project switch, focus does not return to the toolbar button that held it.

## How it was reviewed

Every PR ran exact-head CI on Linux, macOS and Windows, and post-merge CI on `main`. Most had fresh-context reviews, which found real defects repeatedly, including in merged code (#386 led to #387). Those reviews are by the same model, not by people. Alibaba Open Code Review ran as a delegated review on #362 only; elsewhere only CI's delegate-review ran, which produces a spec, not a review. Goldfish reviews wait on free quota. These gaps stay open for the release gate to judge.

**A gap this exit found:** #380 and #385 changed behaviour the dogfooding driver relied on, and CI does not run that driver, so six of seven projects stopped at the next rerun. The fault was in the driver, and #392 fixed it. Earlier passes at `dd01709` on code-only layers were on behaviour since removed. The driver must be rerun for P10 on the exact candidate, as P10 requires.
