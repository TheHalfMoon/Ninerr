## What runs
`scripts/dogfood/run.mjs <sources> <work> <project>` drives Ninerr on one project, as a person and an agent use it.

**Setup**
- The project is first copied into `<work>/<name>/source`. Ninerr writes only to that copy and to its own projects folder. A check confirms the fetched folder was never written.
- The studio host starts as `npm start` starts it.
- The editor is driven in Microsoft Edge through playwright-core. Every request it makes outside the host is aborted and recorded.

**The journeys:**
- **A, import and inspect.** Connect the codebase and bring components in, both in the editor and every component through the host API. For an HTML site, import its pages. Then compare the layers with the source.
- **B, visual editing in the editor.**
  - Select by clicking on the canvas, at depth.
  - Edit text and style in the inspector.
  - Insert a box, move it and resize it by dragging, and delete.
  - Undo and redo.
  - Each step is checked against the document and the rendered page.
- **C, persistence and recovery.**
  - Save, close, and reopen in a new host: the document must be byte-identical, and the store must not be written.
  - The history must list the earlier changes after the reopen (#231).
  - A crash (the host process is killed) after an acknowledged edit.
- **D, source write-back.**
  - Review a change as a diff, then write it: exactly the planned field changes.
  - An outside change elsewhere in the file, then a second write-back with no conflict.
  - A text changed in both places: a conflict that shows both values, and taking the file's value (#236).
- **E, an MCP agent.**
  - Inspect the project, edit texts, move and delete layers (the delete approved in the editor).
  - The person's undo and redo, and Revert of the agent's change.
  - A refusal when the agent asks for another project.
- **F, security and privacy.**
  - No request leaves the host.
  - The canvas frame is sandboxed without scripts, and no imported script element reaches it.
  - The editor raises no errors.
- **G, timings** of each step: median, 95th percentile, maximum and sample count.

`scripts/dogfood/report.mjs <work>` writes the tables below from the runs' `result.json` files, so that no figure is copied by hand.

## How to reproduce
```
node scripts/dogfood/fetch.mjs <sources>
node scripts/dogfood/run.mjs <sources> <work> <project>      # once per project
node scripts/dogfood/report.mjs <work>
```
`NINERR_TEST_BROWSER` names a Chromium or Edge executable. The final run took the seven projects one after another on an otherwise idle machine, with the default 10 samples per repeated step. `run.mjs` exits 1 when a check fails or the run stops on an error.

## Classifications of what stays open
- **#283, an HTML import's linked stylesheets.** A documented limitation and a designed enhancement, not a P08 blocker.
  - An import is one HTML file, and nothing it links to is fetched. That is deliberate: no request leaves the host.
  - The design model has no stylesheets. Carrying a site's CSS needs a scoped stylesheet per imported frame, which is design-model work.
  - Utility-class sites such as the Tailwind codebases are a separate question: their classes need the project's build to mean anything.
- **Undo after an agent's edit.**
  - The editor's Undo is per actor by design: the person's Undo never takes back an agent's change. An agent's change is reverted from the history.
  - The finding is that a person may not look there. This is UX for P09, where the history and undo affordances are designed.
- **No reorder, group or reparent control in the editor.** The model and the MCP tools support moving layers. The editor's controls for it belong to P09.
- **#291, write-back conflict follow-ups.** Minor, and none of them loses data. They are for P09 or P10.

## Timings, and what they are not
- The timings are one run on one machine (Windows 11, Intel Core i5-13420H, Node 24, Edge). They are indicative, not budgets.
- An editor step is measured from the action until the editor holds the document's new revision. The drawing of the canvas is checked separately and not timed.
- The repeated text edit also includes selecting the layer in the layers tree.
- The repeated text edit on sb-admin-2's 1,857 layers is the slowest repeated editing step: p50 288 ms, p95 382 ms. Its reopen in the editor took 404 ms. Below a few hundred layers, the same step has a p50 of 81–126 ms.
  - Editing cost grows with the document (#252).
  - At the projects' sizes it stays below the gate-13 end-to-end budget of 750 ms, which applies at 10,000 layers.

## What this evidence does not show
- **Platform.** Only Windows was dogfooded. Linux and macOS run the same journeys' building blocks in CI (`tests/journeys.test.mjs` and the editor tests), not this driver.
- **Screenshots.** The runs' screenshots stay with their result files in the local work folder. They are not committed.
- **Reach.** No project's own build, tests or runtime were exercised. Ninerr reads source, imports components and writes back literal text and attributes.
